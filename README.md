# Contact Book Python
A simple contact book application built using Python dictionaries and functions.

## Features

- Add Contact
- View Contact
- Edit Contact
- Delete Contact
- List All Contacts
- Menu Driven Interface

## Concepts Used

- Python
- Dictionaries
- Functions
- Loops
- Conditional Statements

## How To Run

1. Download the project
2. Open command prompt or terminal
3. Run the file:
   `contact_book.py`

## How To Use

1. Select 1 to add a contact.
2. Select 2 to view a contact.
3. Select 3 to edit a contact.
4. Select 4 to delete a contact.
5. Select 5 to list all contacts.
6. Select 6 to exit.
